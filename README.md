# 🎂 Сайт-поздравление "Нуль Какашка"

Добро пожаловать в репозиторий самого душевного (и немного безумного) проекта — интерактивного сайта-поздравления с днём рождения для нашего дорогого друга Нуль! 🥳

Здесь нет скучных открыток. Только код, любовь, арты от друзей и немного магии.

## ✨ Что внутри?

- **Главная страница:** Встречает именинницу гифкой, праздничной гирляндой и слот-машиной (да, можно испытать удачу и сорвать джекпот!).
- **Паутина с фотографиями:** Интерактивная паутина, на которой висят полароиды с фактами о друзьях. Карточки переворачиваются (3D-эффект!), а вся паутина плавно «дышит».
- **Личные страницы:** У каждого друга (Корделия, Саня, Лори, Ginger, Диша, Вителька, Пробел) есть своя страничка с уникальным поздравлением и артами.
- **Мини-игра «Поймай Лин»:** На странице разработчика спрятана мини-игра на реакцию. Поймай 10 голов Лин — и тебя ждёт салют! 🎆
- **Адаптивность:** Всё это великолепие отлично выглядит как на компьютере, так и на телефоне.

## 🛠️ Стек технологий

Проект написан на чистом (ванильном) коде, без тяжелых фреймворков:
- **HTML5** — структура страниц.
- **CSS3** — вся визуальная магия: анимации (парящие карточки, гирлянда, свечение), градиенты, вишнево-оранжевая палитра и адаптивность.
- **JavaScript** — логика выезжающего меню, работа слот-машины, переворот карточек и мини-игра с салютом.
- **Canvas API** — для отрисовки салюта.
- **GitHub Pages** — хостинг для нашего шедевра.

## 🚀 Как запустить локально?

Если ты хочешь что-то подкрутить в коде:
1. Склонируй репозиторий: `git clone https://github.com/gulfina-dev/Milubimsiskiphilla.git`
2. Открой папку с проектом.
3. Запусти файл `index.html` в любом браузере. (Или используй расширение Live Server в VS Code).
